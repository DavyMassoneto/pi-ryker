# Rename map

Maps the Portuguese file and symbol names used by the build plan (`docs/plano-etapas-2-6.md`) to the English names in the code.

## Persisted and model-facing names kept as they were

These names are stored in `.ryker/discussao.json`, in session entries, or are seen by the model, so renaming them would break existing saved state or the tool contract. Their TypeScript types are renamed (see below) but the property names and string values stay:

- Tool names: `ryker_perguntar`, `ryker_temas`, `ryker_documento`; command `/ryker` and its `reabrir` argument; entry types `ryker-discussao` and `ryker-correcao`; environment variable `RYKER_ABRIR`.
- Persisted state (`DiscussionState`, formerly `Estado`) properties: `versao`, `fase`, `pedido`, `idioma`, `criadoEm`, `temas`, `perguntas`, `anterior`, `modeloEtapa`, `pausado`, `revisao`, `documento` (`caminho`, `geradoEm`), `aprovadoEm`.
- `Topic` (formerly `Tema`) and `Closure` (formerly `Fechamento`) properties: `id`, `titulo`, `secao`, `criadoPor`, `status`, `texto`, `motivo`, `quando`, `origem`, `revisa`, `substituidoPor`, `revistoEm`, `criadoEm`, `reabertura`, `historico`; `Origin` (formerly `Origem`) uses `tipo` and `perguntaId`.
- `Question` (formerly `Pergunta`), `Review` (formerly `Revisao`), `Finding` (formerly `Achado`), `FindingResolution` (formerly `ResolucaoAchado`), `Previous` (formerly `Anterior`) keep their persisted properties (`pergunta`, `opcoes`, `recomendada`, `resposta`, `livre`, `em`, `cancelada`, `achados`, `bloqueante`, `exigeDecisaoMacro`, `resolucao`, `tipo`, `como`, `ferramentas`, `modelo`, ...).
- Tool input shapes that mirror the tool schemas: `QuestionInput`, `TopicItem`, `ReopenItem`, `Synthesis`, `Resolution` keep `tema`, `pergunta`, `opcoes`, `recomendada`, `acao`, `titulo`, `secao`, `texto`, `origem`, `motivo`, `quando`, `revisa`, `nota`, `achado`, `como`.
- Tool result `details` keys: `respondidas`, `pausou`, `abertos`, `aprovado`, `reabertos`, `bloqueantes`.
- Status and origin string values (`aberto`, `decidido`, `suposto`, `adiado`, `descoberta`, `documento`, `aprovacao`, `aprovada`, `usuario`, `fonte`, `agente`, `base`, `modelo`) and the base topic ids (`problema-job`, `para-quem`, ...).
- Every user-visible and model-visible string (UI labels, notifications, prompts, tool descriptions, HTML content).
